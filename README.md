## 📌 Featured Projects

### 🎬 ScoreFilm *(Personal project · In progress)*
A microservices-based platform for rating movies, TV shows, anime, and documentaries through a multidimensional review system rather than a single overall score.
* Spring Boot · NestJS · GraphQL · PostgreSQL · MongoDB · Redis · Docker
* Monorepo with separate authentication and catalog services
* Secure authentication using Spring Security, JWT (RS256), and JWKS for communication between microservices
* GraphQL catalog service backed by MongoDB with TMDB integration for audiovisual metadata
* Features include reviews, favorites, watchlist, filtering, pagination, and unit testing
* Redis caching with a Cache-Aside strategy currently being integrated into the catalog service

🔗 Repository: https://github.com/Camil0MV/ScoreFilm

### 🏦 Digital Banking Backend *(University project · Completed)*
REST API for a digital banking system developed as a team following Scrum and managed through Azure DevOps.
* Java 21 · Spring Boot · PostgreSQL · Spring Security · JWT · JPA/Hibernate
* Layered architecture using Controller → Service → Repository
* Implemented authentication and authorization with Spring Security and JWT
* Developed and configured backend components related to security, data models, and application configuration
* Documented and tested the API using Swagger and Postman

🔗 Live Demo: https://banco-digital-backend-u3ts.onrender.com/swagger-ui/index.html#/

### 🦟 Epidemiological Data Analysis — Dengue in Colombia *(University project · Completed)*

Exploratory analysis of epidemiological data on dengue cases in Colombia from 2010 to 2024, focused on understanding distributions, relationships, temporal patterns, and data quality.
* Python · pandas · NumPy · Matplotlib · Seaborn · SciPy · Statsmodels · scikit-learn
* Performed data preprocessing and validation, including missing values, duplicates, data types, and logical consistency
* Conducted univariate and multivariate analysis, correlation analysis, and temporal pattern analysis
* Detected and analyzed outliers and applied data transformations during the preparation process
* Developed reproducible Jupyter notebooks and visualizations to communicate analytical findings

🔗 Repository: https://github.com/Camil0MV/dengue-colombia-analisis
